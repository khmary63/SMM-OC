2. **Windsor.ai** — коннектор `instagram` подключён, действие `create_video_post`:
   MP4/MOV по публичному URL, до 1 ГБ, 3 сек–15 мин, 9:16, `caption` до 2200 символов,
   `cover_url` / `thumb_offset`, `share_to_feed`. Instagram публикует любое одиночное
   видео в ленту как Reel. Музыку прикрепить нельзя.

**Рендер:** `services/video-worker` (FFmpeg) — готов принимать задачу «наложить текст на видео».

**Расписание:** n8n Schedule Trigger, таймзона воркфлоу уже `Europe/Moscow`.
Встроенный в сессию cron не подходит: живёт только пока открыта сессия и умирает через 7 дней.

## 3. Блокеры

### 3.1. Нет источника «вирусные Reels за 24 часа»

Instagram Graph API не отдаёт чужой контент и тренды. Windsor.ai по коннектору `instagram`
читает только метрики самого `@makhabarova`. Варианты:

- **A.** Платный трендовый сервис (Apify Instagram Scraper и подобные) → HTTP-нода в n8n.
  Единственный вариант, который буквально закрывает «за последние 24 часа».
- **B.** Переиспользовать существующий `1 Поиск виральных YouTube-роликов` (`GzMABQd48Rx9fqlU`),
  перенастроив на англоязычные каналы нужных ниш. YouTube Data API даёт просмотры и дату честно
  и бесплатно; заголовки Shorts и Reels в этих нишах пересекаются почти полностью.
- **C.** Веб-поиск по подборкам вирусных хуков — данные вторичные и с лагом в несколько дней.

Рекомендация: **B** как база (инфраструктура уже написана и отлажена), **A** доплатой,
если нужна именно Instagram-выборка.

в верхней и нижней третях — туда ляжет заголовок и интерфейс Instagram.

### 3.3. Музыка Instagram недоступна через API — принципиально

Meta Content Publishing API не позволяет прикрепить трек из внутренней библиотеки Instagram.
Это ограничение платформы, обходится только одним из трёх способов:

- **A. Полуавтомат (рекомендую).** Buffer с `schedulingType: "notification"`: в слот приходит пуш,
  вы открываете Instagram, вставляете готовое видео, выбираете музыку в приложении, жмёте
  «Поделиться». ~20 секунд ручной работы, зато трек из библиотеки IG и полный охват от него.
- **B. Вшить трек в MP4.** `services/video-worker` подмешивает лицензированный аудиофайл.
  Полностью автоматически, но это не музыка Instagram: алгоритм не подхватит её как трендовую,
  а при чужих правах возможен мьют или страйк. Нужна своя лицензионная библиотека.
- **C. Публиковать без звука.** Полностью автоматически, охваты заметно ниже.

### 3.4. Базы знаний «ИИ-копирайтер» и «ИИ-переводчик» недоступны

Это проекты на claude.ai; из рабочей сессии и из n8n их инструкции не читаются.
Ни в Google Drive, ни в репозитории файлов с такими названиями нет.
Нужно выгрузить их содержимое в одно из мест: `docs/` этого репозитория, n8n Data Table,
или отдельные skills. До этого шаги 4–5 выполняются «общим» копирайтингом, то есть не по вашей методологии.

### 3.5. Публичный URL для видео

Instagram и Buffer скачивают видео по прямой ссылке. Ссылка Google Drive для этого не годится
(отдаёт HTML-страницу, а не файл). Отрендеренный MP4 нужно класть на статику вашего сервера
(в `docker-compose.yml` для этого уже есть куда добавить раздачу `/assets/`) и отдавать прямой https-URL.

## 4. Предлагаемая схема

Новый n8n-воркфлоу `9. Instagram Reels Daily`, отдельный от `7.3` (тот завязан на HeyGen-пайплайн
и таблицу «Дипломный проект» — смешивать не нужно).

```text
Schedule Trigger (9:12 и 19:12 МСК, Europe/Moscow)
  └─> HTTP: источник виральных заголовков за 24 ч            [§3.1]
      └─> Claude: фильтр по 9 тематикам → выбор 1 хука
          └─> Claude: пост по базе «ИИ-копирайтер»           [§3.4]
              └─> Claude: перевод по базе «ИИ-переводчик»    [§3.4]
                  └─> Google Drive: случайный файл из папки  [§3.2]
                      └─> video-worker: заголовок поверх видео, drawtext,
                          0..конец, Inter/Montserrat Bold, белый + чёрная подложка,
                          9:16, безопасные поля 250 px сверху / 350 px снизу
                          └─> выгрузка MP4 на статику → публичный URL   [§3.5]
                              └─> Buffer create_post (reel)             [§3.3]
                                  └─> Google Sheets: лог слота, ссылки, статус
```

Дедупликация: лист с историей опубликованных хуков; выбранный заголовок сверяется с последними
30 днями, чтобы не повторяться.

Два слота в сутки = два срабатывания триггера, по одному рилсу в каждом.
Минуты смещены с :00 намеренно — ровные минуты дают всплеск нагрузки на всех внешних API сразу.

3. **Выбрать источник трендов**: A (платный скрапер), B (перенастроить YouTube-воркфлоу), C (веб-поиск).
4. **Выгрузить базы знаний** «ИИ-копирайтер» и «ИИ-переводчик» — файлами в `docs/` или ссылкой на Google Docs.
5. **Подтвердить объём**: «по два рилса утром и вечером» — это 2 в сутки (по одному в слот) или 4?
6. **Подтвердить аккаунт**: публикуем в `@makhabarova`?
