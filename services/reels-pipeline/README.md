# Reels Pipeline

Ежедневная подготовка Reels для Instagram: отбор вирусного хука → текст поста →
перевод → подложка → рендер заголовка → доставка.

Сейчас готов **шаг 1: отбор хука**. Остальные шаги добавляются в этот же сервис.

## Модули

| Файл | Назначение |
|---|---|
| `niches.js` | 9 тематик из ТЗ и поисковые запросы под каждую |
| `trends.js` | отсев чужеязычных, ранжирование и дедупликация, **не знает про источник** |
| `sources/youtube.js` | источник трендов на YouTube Data API v3 |
| `bin/probe.js` | живая проверка: печатает хуки, которые источник отдаёт сейчас |

## Контракт источника

Источник — объект с методом `fetchCandidates()`, возвращающий
`{ candidates, errors }`. Кандидат единого формата:

```js
{
  id: "abc123",
  source: "youtube",
  title: "I Quit My Job After This",
  url: "https://www.youtube.com/shorts/abc123",
  niche: "ai_income",
  views: 84000,
  publishedAt: "2026-09-21T10:00:00Z",
  channel: "Some Channel",
}
```

Отбор (`trends.js`) работает только с этим форматом, поэтому источник сменный:
чтобы перейти на другой сервис, достаточно добавить файл в `sources/` с тем же
контрактом — ранжирование, дедупликация и всё, что ниже по пайплайну, не меняется.

## Как отбирается хук

**Ранжирование — по скорости, а не по сырым просмотрам.** В окне 24 часа
ролик, вышедший час назад с 50 000 просмотров, вируснее вчерашнего с 100 000.
Метрика — просмотры в час; возраст снизу поджат одним часом, иначе свежий
ролик давал бы бесконечную скорость.

**Дедупликация — по смыслу, а не по строке.** Вирусный хук расходится по
авторам с мелкими правками: «I Quit My Job After This» и «She Quit Her Job
After This» — один и тот же заголовок. Сравниваются доли общих значимых слов
(мера Жаккара), порог 0.6. Проверка идёт и против истории публикаций за
последние дни, и внутри текущей выборки.

**Язык — отдельным фильтром, до ранжирования.** `regionCode=US` и
`relevanceLanguage=en` у источника — подсказки ранжирования, а не фильтр:
в выдаче по английскому запросу регулярно оказываются хинди, японский и
арабский. Для англоязычной ленты такой хук бесполезен, поэтому заголовок
проверяется на долю латинских букв (порог 0.8). Хэштеги при этом
выбрасываются: они латинские независимо от языка ролика, и гроздь
`#HealthTips #YouTubeShorts #Shorts` иначе перевешивает короткий заголовок
на хинди.

Порядок важен: сначала ранжирование, потом дедупликация — тогда из группы
похожих заголовков остаётся самый вирусный, а не случайный.

## Ключ YouTube API

Ключ читается из `YOUTUBE_API_KEY`. **В репозиторий его класть нельзя.**

- локально и на сервере — переменная окружения (`.env`, docker-compose);
- для облачной сессии Claude Code — поле `Environment variables` в настройках
  окружения, или `API credentials` на планах Pro/Max, где ключ не виден агенту.

Получить: Google Cloud Console → включить *YouTube Data API v3* → создать
API key. Ключ стоит ограничить этим одним API.

### Квота

Дневной лимит по умолчанию — 10 000 единиц. `search.list` стоит 100, `videos.list` — 1.
Девять ниш по три запроса, дважды в сутки — примерно 5 400 единиц. Запас есть,
но добавлять запросы в `niches.js` без пересчёта не стоит.

## Проверка

```bash
node --test test/trends.test.js          # 23 теста, без сети

YOUTUBE_API_KEY=... node bin/probe.js    # живая выдача, ничего не публикует
YOUTUBE_API_KEY=... node bin/probe.js --niches money,ai_income --limit 5
```

`probe.js` только читает и печатает — безопасно запускать сколько угодно,
единственная цена это квота.
